# homebrew-tap

Homebrew tap for Ultra's tools.

```sh
brew install ultradotdev/tap/tide
brew install ultradotdev/tap/gantry
```

- [Tide](https://ultra.dev/tide): terminal-native IDE for code, Git, databases, shells and agent CLIs.
- [Gantry](https://github.com/ultradotdev/gantry): HomeKit bridge for UniFi Protect cameras, doorbells and sensors.

The formulas are generated by each project's release process. Do not edit them here.
