# homebrew-tap

Homebrew tap for Ultra's tools.

```sh
brew install ultradotdev/tap/tide
brew install ultradotdev/tap/gantry
```

- [Tide](https://ultra.dev/tide): terminal-native IDE for code, Git, databases, shells and agent CLIs.
- [Gantry](https://github.com/ultradotdev/gantry): HomeKit bridge for UniFi Protect cameras, doorbells and sensors.

The formulas are generated by each project's release process. Do not edit them here.

## How a formula gets updated

Nothing is pushed to `main` directly. A release opens a pull request, and
`.github/verify_formula.py` decides whether it may merge. It lets through
one thing only: an existing formula with a higher version and new
checksums, where every file the formula names downloads from that
project's release and matches its checksum. Anything else, including a
change to the formula's own steps or to the check itself, needs the owner.
